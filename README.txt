SISTEMA CHECKLIST — VERSÃO 1

O que já está funcionando:
- Novo checklist
- Cadastro da área
- Cadastro de várias atividades
- Horário de cada atividade
- Marcação OK/concluído
- Observação geral
- Histórico de todos os checklists
- Filtro por data
- Busca por área/atividade
- Visualização detalhada dos registros
- Nome da empresa
- Nome do funcionário
- Upload de logo
- Funcionamento offline depois de carregado
- Estrutura PWA para instalação no Android

IMPORTANTE SOBRE OS DADOS:
Esta primeira versão salva os checklists no armazenamento local do navegador/dispositivo.
Isso significa que os registros não são compartilhados automaticamente entre aparelhos.

PARA INSTALAR NO ANDROID:
1. Publique esta pasta em um endereço HTTPS (por exemplo, GitHub Pages).
2. Abra o endereço no Chrome do Android.
3. Use "Adicionar à tela inicial" / "Instalar aplicativo", conforme aparecer no Chrome.
4. O sistema abrirá como aplicativo.

PRÓXIMA EVOLUÇÃO:
Podemos transformar o sistema em uma versão com banco de dados e login, permitindo:
- vários funcionários;
- histórico centralizado;
- administrador;
- registros por área;
- relatórios;
- sincronização entre aparelhos;
- backup;
- edição/exclusão controlada.

O projeto foi separado em HTML, CSS e JavaScript para facilitar o aprendizado posteriormente.
